# Privacy Policy

`analyzerkit` is an open-source Shared project discovery, source scanning, LMDB caching, control flow, and SARIF reporting library for Swift static analyzers, licensed under the MIT License.

## Data Collection and Telemetry

- **No telemetry or analytics:** `analyzerkit` collects, stores, and transmits **zero** telemetry, usage analytics, crash reports, or personal data.
- **No network access:** `analyzerkit` performs no outbound network requests and contains no tracking, licensing, or phone-home logic.

## Data Processed Locally

As a compiled Swift library, `analyzerkit` processes only the in-memory inputs and local filesystem paths provided directly by the host application or tool that links it.

## GDPR and Enterprise Compliance

`analyzerkit` operates strictly within the calling process and transmits no data to external services.
