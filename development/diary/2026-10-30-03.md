# 2026-10-30 — fcheck's rule fixes (0025)

The probe script turned into seven red tests, and every one failed for the reason the probe gave. The green fixed
five rules in one go, and the probes now give every expected verdict.

- **F1:** the second pass used to be a sequential loop over files that contained an acquirer's name anywhere in
  their text. It now reruns, through `CorpusScanner`, only the files whose calls name a new acquirer, and repeats
  until no acquirer is added.
  - The cache needed a decision. Shards carry one salt each, so a round salted with the acquirers' digest would
    overwrite pass 1's shards in the same workspace. Each round gets a workspace of its own instead, and a warm run
    replays the same rounds from the cache.
- **F5:** the acceptance run found the only regression. ask writes `flush(directory)`, a helper that `fsync`s the
  directory, and the first cut took the exact name `flush` for a file flush. The descriptor's name now decides, and
  that case became a test before the fix.

Findings are identical on maintastic and on all twenty g-cqd packages. The fixes remove false positives and add
findings that only small cases show. Cold CPU rose by 8% (one more walk per file for the called names); wall time
did not move.
