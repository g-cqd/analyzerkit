# 2026-11-01 — promotion steps 1 to 4 (0067)

Carried out in order, each shared piece with a red commit first and each tool compared against its previous build.

The report layer was the part that surprised. The three `ReportFormatter`s differed in small things that a generic one has to
choose: arcleak and dolly counted degraded entries for "every file skipped", deadwood counted unique whole-file paths. A
red test for the second came first (a file degraded twice is not two files, and a partly analyzed file is not skipped), and the
shared default is deadwood's. That is the only behaviour change in the report layer; the other bytes matched on the fixtures and
on the other tools' sources, cold and warm, with a baseline written and applied.

`PathPresentation` and `AnalysisReport` were left in the tools on purpose: what remained was a choice per field, and a shared
version would have been a closure per field. 0067 says so.

The embedding providers moved without a changed vector (the deterministic one is the oracle) and the real
NLContextualEmbedding ran in all three tools. The Hugging Face provider was not run against a bundle; there is none here.

Step 5 changes cache payloads, so it has its own entries (0068 to 0070) and was not started.
