# 2026-10-29 (16) — Roadmap 0013: exit statuses and the shared option groups

## Probe first, again

`research/probes/exit-codes.py` runs nineteen scenarios through each tool's analysing command in a temporary repository
root: clean code, one finding with each severity (set through the tool's configuration where it has one), with and without
`--strict`, malformed and missing configuration and baseline files, an unwritable `--write-baseline`, an unknown flag, a
missing path, an empty directory, a file that is not UTF-8, a file with mode 000.

Three tools agreed on everything (errors fail, `--strict` adds warnings, notes never). fcheck passed error findings,
exited 64 for configuration and baseline errors and 1 for an unwritable baseline, and 0 when it could read nothing; modeler
exited 0 for a missing path, an empty directory and nothing read. A CI gate takes 0 for "clean". ADR-0006 said none of
this precisely; ADR-0018 now does, and adds that writing a baseline is an output (74), not a configuration (78).

## Red, then green, in five tools

One `ExitCodeContractTests` per tool, the same table, rows a tool cannot express (modeler has no configuration, baseline
or severities) left out. Red rows matched the probe exactly, plus one that was the test's own mistake: deadwood reports
`struct Clean {}` as an unused type, so the clean fixture became an `@main` type. The fixes: the three tools drop their
local `ExitStatus` and failing rule for `AnalyzerCLI`'s and route the baseline write to 74; fcheck tells a configuration
failure (78) from a `--rules` usage error (64) and uses `RunOutcome.status` with its degraded count; modeler checks its
inputs in the shared corpus loader of every subcommand. modeler's pin moved forward several analyzerkit revisions; its
suite stayed green.

After: the probe's columns agree except on a file that is not UTF-8, which fcheck and modeler decode lossily (0045).

## The option groups, after correcting the ADR

Checked ADR-0006's table against `--help` of the five before coding; four lines were wrong (`--report-new-since` takes a
baseline file; `--include-tests` means test *and generated*; dolly's `--semantic` is a rule, not an experiment;
`explain <id>` versus `rules <id>`). ADR-0019 supersedes it. The groups were red on alias folding, deprecations, `--rules`,
`requested` and the contradictions, then green; a region list folded from old and new spellings parses with the
`RegionSelection` every tool uses. The help is pinned in a golden; recording it showed a doubled default on `<paths>` and
placeholders echoing option names, both fixed before recording.
