# 2026-10-31 — wave 1 shipped, consumers moved (0030, 0031), IndexQueries adopted (0054)

All five wave-1 tags passed CI and published, and the release-note lint filled each note. dolly and deadwood were
tagged last, once their `main` CI was green. fcheck's bundle checksum, recomputed from the download, matches its note.

The consumers now share one script and one lock, both in aemi. Each repository keeps only a bootstrap that names an
aemi commit and its corpus. Moving them found two things that predate the wave:

- AemiRegex's gate was already red: an unused `ByteRange`. It is deleted.
- AemiProtobuf had pinned fcheck at a commit from before the rule learned `dropFirst`. The release finds three
  slices of ASCII digits, which are accepted. A rule that knew the predicate admits only ASCII would not report them.

IndexQueries has three users now: arcleak, deadwood and swift-search. deadwood's index paths now come out as the
corpus spells them, and the output on maintastic with the Xcode store is byte-equal: 90 findings, and the same stderr.
swift-search moved its resolver onto `IndexQueries` (base names, selectors, containers and the regex scan, for which
`occurrences(whereName:)` was added) and its pins to the wave. All 64 of its tests pass, the index suite included. Its
commit `db8edad` is local: the repository has no remote.
