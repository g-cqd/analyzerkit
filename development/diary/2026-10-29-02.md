# 2026-10-29 (2) — Speed, surface, consumers, and the owner's decisions

## Speed

Release builds of the five tools on maintastic; research `2026-10-29-performance-on-maintastic.md`. The figures that set
the roadmap:

- **deadwood never caches** on this project ("skipped facts cache larger than 64 MiB"): warm 3.6 s = cold 3.6 s. maintastic
  already works around it with `--no-cache`. Its index run takes 23.8 s, of which the summary-only pass is the largest part.
- **fcheck is quadratic** on SwiftUI chains: `CallSite.callee` re-describes the called expression on every access.
  `ResourceRule` costs seven times the parse.
- **Warm runs are serial**: about 1.2 cores used. Discovery (a Foundation stat dictionary per entry), the repository-root
  walk (one `.git` probe per level per file, no memo), and the cache decode (generic `Codable`, on the main thread) are
  most of it. dolly's 27 MB and modeler's 10.8 MB JSON caches cost about what parsing does.
- **Caches are never evicted**: 226 MB deadwood (169 MB of it a legacy file from July), 140 MB arcleak, 62 MB dolly.

## Surface

Research `2026-10-29-surface-and-duplication.md`. `--exclude` is a region on the command line and a path in the files; the
same configuration selects 2,584 to 2,973 files depending on the tool; exit codes differ; duplicated code is 84–100 %
similar for suppression, baseline and the formatter.

## Consumers

Research `2026-10-29-consumers-and-ci-contract.md`. Four copies of `analyzers.sh` at three version sets; aemi's workflow
defaults two releases behind; AemiProtobuf's roadmap 0015 stale (fcheck and modeler 0.1.1 publish archives and bundles);
maintastic pins bundles by checksum, decodes `schemaVersion == 1` and six finding keys, and treats 64/70/74/78 as "did not
run".

## The owner's decisions

- Records in the format of ask, TerminalKit and AemiProtobuf (ADR-0001: `development/`, as ask decided in its `development/adr/0128-…`).
- Shared configuration name left to this work: `.swift-analyzers.json` (ADR-0007).
- Index-store support inside analyzerkit for now (ADR-0004).
- Report schema stays version 1 (ADR-0009).
- Internal formats binary, with AemiProtobuf where nothing external reads them (ADR-0010).
- A real interner, engineered for speed (ADR-0012); aemi's `InternedStrings` is compile-time obfuscation and does not fit.
- The directory walker: placement reassessed (ADR-0013, Aemi, because ask's `ProjectLister` and KittyCode's
  `SymbolDiscovery` are second consumers), parallel and concurrent.
- Every item red-first (ADR-0002); every release with an explicit consumer breakdown (ADR-0015).
