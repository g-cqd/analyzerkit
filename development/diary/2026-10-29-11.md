# 2026-10-29 (11) — Roadmap 0008: layouts and DerivedData

## Red, then green

Five fixtures failed against a nil layout stub: a package, an Xcode project containing local packages and an embedded
private workspace, a workspace with two worktrees and unrelated DerivedData names, a direct custom build root, and
repository-boundary/common-directory fallback. The implementation uses ProjectModel -> SourceCorpus (no cycle), the
common canonical input directory, an ancestor search bounded by .git, and SourceDiscovery for manifests/containers.
The root precedence is now spelled out in ADR-0003, not left to the word “first”.

DerivedData matches canonical WorkspacePath to a discovered container. LastAccessedDate orders candidates; absent dates
use directory mtime, ties use path. Directly supplied custom roots may omit info.plist; children may not, and present
metadata must match even on a direct root. Missing/malformed metadata and other worktrees lose, regardless of names.
The store root stays DataStore, never its versioned subdirectory. Population/format validation stays with the reader.

A second red test found unbounded plist reads: a valid oversized plist was accepted. BoundedFileReader now caps metadata
at 1 MiB before decoding. Added XML/binary metadata, mtime ordering and symlink spelling coverage too. All seven tests
pass. FoundationEssentials is preferred where available, as in the existing shared filesystem code.

## Tools and real tree

Both tools' adoption tests failed before changing their path finders; deadwood also chose the nested package as root.
Arcleak now uses CLI input paths for its root, deadwood all analyzed paths; their folder-name DerivedData guesses are
deleted. Existing SwiftPM candidate priority and store validation are deliberately unchanged. Full suites pass (208 and
366); the dependency was then repinned to the bounded-reader/import commits and the adoption/probe tests rerun.

A throwaway shared-model probe and a path-finder probe in each tool, removed afterward, checked maintastic without
opening an index or changing any consumer file. From the root and ShareAPI/Sources: the same root, 17 packages, one
container, exactly the fygsyifvnhrizrfdclbpemklqblj worktree's DataStore. The hcibuwrtkoxbkraeiypszwcpjjzp worktree loses.
No claims yet about dylib selection or index semantic coverage: 0009 and 0023/0024 own those. No CI work in this pass.

## Performance finding and scope boundary

The full suites slowed significantly for fixtures outside a repository: the ancestor search must list the shared temp
directory. A read-only Python measurement found 261,922 entries there, listing time 15–48 s depending on concurrent
activity. The seven layout tests took 105 s under concurrent suite activity, versus ordinary maintastic path-finder
probes at 0.60–0.73 s each for two discoveries. These are observations, not quiet-machine benchmarks. Added the shallow,
very-large-directory case to 0006's probes and 0029's budgets; no stale global root cache and no duplicate walker here.

Project-derived test/generated/script classification needs target/product parsing, not filesystem discovery: split into
0043, blocking the tool migrations. ADR-0003 still requires it; it is not claimed done. Xcode auto-build stays in 0033,
store normalization in 0010, CLI/config adoption for the other tools in their migrations. Next is 0009: toolchain
resolution and trust. Commits and verification details are in roadmap 0008.
